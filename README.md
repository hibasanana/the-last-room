# 🔎 The Last Room

A desktop mystery detective game built with **Python and Tkinter**.

## 🕵️ About the Game

Alex Morgan has disappeared from Room 204 of a hotel.

The door was locked from the inside, and four people were present in the hotel.

Your job is to investigate the room, collect evidence, interrogate suspects, and determine who is responsible for Alex's disappearance.

## 🎮 Features

* 🔎 Investigate different areas of the room
* 📋 Collect and review evidence
* 👥 Interrogate four suspects
* 💬 Ask suspects different questions
* 🔐 Discover clues that affect interrogation responses
* ⚖️ Make a final accusation
* 🏆 Multiple case outcomes
* 🖥️ Desktop GUI built with Tkinter

## 👥 Suspects

* **Maya** — Hotel Receptionist
* **Arjun** — Alex's Friend
* **Daniel** — Hotel Manager
* **Sara** — Hotel Guest

## 🛠️ Built With

* Python
* Tkinter

## 🚀 How to Run

Make sure Python is installed on your computer.

Clone the repository:

```bash
git clone <your-repository-url>
```

Navigate into the project:

```bash
cd the-last-room
```

Run the game:

```bash
python app.py
```
